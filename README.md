# multigroup_3S-LVAR_simulation

This repository contains the code for the simulation study of the publication [Modeling Between-Group Differences in Dynamics of Psychological Constructs in the Presence of Measurement Non-Invariance: A Stepwise Approach (Rein, Vogelsmeier, Vermunt, van Roekel, De Roover, 2026)](https://osf.io/preprints/psyarxiv/7d63n_v1).
